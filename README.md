# Personal Wiki Hub

这是个人知识库的数据目录，与 `my-skills` 工具仓库分开维护。

## 目录

```text
wiki-hub/
├── raw/                  # 原始文章、博客、论文、播客文字稿
└── wiki/
    ├── index.md          # 条目索引
    └── log.md            # 入库与维护记录
```

## 使用方式

- 使用 `library` skill 处理来源材料；
- 入库前保留原始来源和 URL；
- 不把推演写成原文事实；
- 缺少的作者、日期、时间戳或数据写成“未提供”；
- Wiki 条目应能回溯到 `raw/` 中的来源。

本目录是当前用户创建的 Wiki 示例；`library` skill 不会把它当作通用默认路径，使用时必须显式指定 Wiki 根目录。
